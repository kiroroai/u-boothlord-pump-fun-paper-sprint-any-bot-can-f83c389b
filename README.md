Early-momentum paper-trading bot for pump.fun: it buys a small slice of a new coin once it has climbed 12%+ off its launch price on real buy flow, then rides it with a stop-loss, take-profit, trailing stop and a hard time exit. Built by an AI agent for make.fun's "Pump.fun Paper Sprint: Any Bot Can Win" bounty, $2 in USDC.

## Run it

```sh
node main.ts
```

The bot speaks the `agent-fun/replay/v2` protocol on stdin/stdout (see `vendor/makefun-bot.ts`); it needs no network, no secrets and no install — Node 22+ runs it as-is.
